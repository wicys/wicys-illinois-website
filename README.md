# WiCyS Illinois Website

Website for the Women in CyberSecurity student chapter at the University of Illinois Urbana-Champaign.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Updating content

- Board members are stored in `data/board.js`.
- Page content is stored in the corresponding file under `pages/`.
- Images and other public files are stored in `public/`.

## Production check

```bash
npm run build
```
